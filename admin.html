登录后台

纯静态站点没有服务端，所以需要一个 Token 来证明你是仓库的主人。用户名、仓库名会从当前网址自动识别（部署后就是你的 GitHub 用户名和仓库名），只需设置一次 Token，之后自动保存在你的浏览器里，不会上传到仓库。

  1. 在 GitHub 创建一个 Token（点这里打开建 Token 页面 ↗）。 建议选 fine-grained（更安全），权限只给 Contents: Read & Write；公开仓库用 public_repo 也够。
  2. 创建后点 Copy 复制到剪贴板（不要关掉 GitHub 那个页面）。
  3. 回到此页，点下面的按钮，自动从剪贴板粘贴并登录。
或者手动填写（复制不了时用）
